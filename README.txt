SAVORY LUXE CATERING — COMPLETE WEBSITE

CONTENTS
index.html  — website page
styles.css  — styles and responsive layout
script.js   — animations, mobile navigation, enquiry email
assets/     — locally included SVG illustrations

HOW TO VIEW
1. Extract the ZIP.
2. Open the savory_luxe_complete folder.
3. Double-click index.html in a web browser.

HOW TO PUBLISH
Upload the contents of savory_luxe_complete (not the outer folder) to a static hosting provider such as GitHub Pages or Netlify. The homepage file must be named index.html.

IMPORTANT CUSTOMISATION
- Replace the Savory Luxe name with your own business name.
- In script.js update BUSINESS_EMAIL with your real email.
- Update descriptions, menu text, images and location to your real business.
- The booking form opens an email draft. It does not store bookings, process payment or send email automatically.
- Images are original locally-created vector food illustrations.
- Google Fonts are optional: if offline, the site uses fallback fonts.
